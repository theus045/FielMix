# Fielmix Concreto

Site institucional desenvolvido para a **Fielmix Concreto**, empresa do ramo de concreto usinado.

O projeto foi criado a pedido do meu pai para a empresa onde ele trabalha, com o objetivo de apresentar os serviços da Fielmix de forma mais profissional, facilitar o contato com clientes e oferecer uma presença digital moderna e responsiva.

## Sobre o projeto

O site foi desenvolvido com foco em:

- apresentação institucional da empresa;
- divulgação dos principais serviços;
- solicitação de orçamento pelo WhatsApp;
- responsividade para computadores, tablets e celulares;
- navegação simples e objetiva;
- identidade visual alinhada ao segmento da construção civil.

## Funcionalidades

- menu de navegação responsivo;
- menu mobile;
- Hero com imagens em transição automática;
- seção institucional sobre a empresa;
- cards de serviços;
- botão para solicitação de orçamento;
- integração com WhatsApp;
- botão flutuante do WhatsApp;
- contato e redes sociais;
- animações ao rolar a página.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git
- GitHub
